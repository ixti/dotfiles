== Dependencies
:yadm:       https://yadm.io/[yadm]
:starship:   https://starship.rs/[starship]
:eza:        https://eza.rocks/[eza]
:delta:      https://dandavison.github.io/delta/[delta]
:difftastic: https://difftastic.wilfred.me.uk/[difftastic]
:bat:        https://github.com/sharkdp/bat/[bat]

NOTE: Most dependencies are optional, but highly recommended.

{yadm} (https://packages.gentoo.org/packages/app-admin/yadm[ebuild])::
  Dotfiles manager.
{starship} (https://packages.gentoo.org/packages/app-shells/starship[ebuild])::
  Prompt generator.
{eza} (https://packages.gentoo.org/packages/sys-apps/eza[ebuild])::
  Modern replacement for the file-listing command-line program `ls`.
{delta} (https://packages.gentoo.org/packages/dev-util/git-delta[ebuild])::
  A syntax-highlighting pager for git.
{difftastic} (https://packages.gentoo.org/packages/dev-util/difftastic[ebuild])::
  CLI diff tool that compares files based on their syntax, not line-by-line.
{bat} (https://packages.gentoo.org/packages/sys-apps/bat[ebuild])::
  A cat(1) clone with wings.


== Install

[source,bash]
----
yadm clone --branch main --single-branch "https://codeberg.org/ixti/dotfiles.git"
----

== Update

[source,bash]
----
yadm pull
----
